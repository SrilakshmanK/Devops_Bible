# 📘 Volume 06 — Version Control with Git & GitHub

## 🎯 Objective

Master Git and GitHub workflows used by professional software and DevOps teams, including repository management, commits, branching, **visual Git history with Git Graph**, merging, rebasing, collaboration, recovery, and Git-based DevOps workflows.

## Outcome

After completing this volume, you should confidently:

* Understand version control and why Git exists.
* Configure Git professionally.
* Understand the working directory, staging area, local repository, and remote repository.
* Create meaningful commits and inspect history.
* Use **Git Graph in VS Code** to understand repository history visually.
* Understand local and remote branches.
* Understand `main`, `origin`, `origin/HEAD`, and `HEAD`.
* Create, merge, rebase, and delete branches.
* Resolve merge conflicts.
* Understand Git internals and the object model.
* Use GitHub for collaboration.
* Work with Pull Requests and code reviews.
* Recover from common Git mistakes.
* Apply Git best practices.
* Understand how Git integrates with CI/CD and DevOps.

## Screenshot-Based Understanding

A Git Graph entry such as:

```text
main    origin    origin/HEAD
│
●  Update: Added mini task...
│
●  Problem solving chapter...
│
●  Volume 1 chapter 3 started
│
●  Volume 1 chapter 2 completed
│
●  Version 1.0.0 Finished
│
●  file structure were initialized
```

should allow you to identify:

* Which branch you are currently on.
* Which remote branch you are tracking.
* Where `origin` points.
* What `origin/HEAD` represents.
* The latest commit.
* Previous commits.
* Commit hashes.
* Authors.
* Commit dates.
* Commit messages.
* The chronological relationship between commits.
