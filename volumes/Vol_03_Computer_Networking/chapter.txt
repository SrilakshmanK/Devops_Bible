# 📘 Volume 03 — Computer Networking & Internet Fundamentals

## 🎯 Objective

Build a strong mental model of how computers communicate, how packets travel across networks, how Internet services work, and how to troubleshoot network failures.

By the end of this volume, you should be able to reason about a network from:

```text
Application
    ↓
Transport
    ↓
Internet
    ↓
Network Interface
    ↓
Local Network
    ↓
Router
    ↓
ISP
    ↓
Internet
    ↓
Remote Server
```

You should understand not only **what** each component does, but **why it exists**.

---

# Volume Philosophy

Do not memorize:

> "TCP is reliable and UDP is fast."

Instead understand:

* What problem does TCP solve?
* What information must be maintained to provide reliability?
* What does that maintenance cost?
* Why might an application choose UDP?
* What happens when packets are lost?
* Who handles the loss?

Similarly, don't memorize:

> "DNS converts domain names into IP addresses."

Understand:

```text
Browser
 ↓
DNS Resolver
 ↓
DNS hierarchy
 ↓
Authoritative DNS
 ↓
IP address
 ↓
Connection
```

The goal is to build a **packet-level mental model**.

# Architecture

Start with:

```text
                    Host Ubuntu
                         │
                Virtual Network
                         │
          ┌──────────────┼──────────────┐
          │              │              │
          ▼              ▼              ▼
       VM-Client      VM-Server       VM-Router
          │              │              │
          │              └──────┬───────┘
          │                     │
          └─────────────────────┘
```

The exact VM topology can be adjusted based on your computer's resources.

Do not build an unnecessarily complicated topology.
